# 🏒 Анти ИИ: Настольный Хоккей 3D

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![Three.js](https://img.shields.io/badge/Three.js-000000?style=for-the-badge&logo=three.js&logoColor=white)
![Offline](https://img.shields.io/badge/Offline-Ready-4CAF50?style=for-the-badge)
![License](https://img.shields.io/badge/License-Free%20to%20Use-blue?style=for-the-badge)

Бесплатная браузерная 3D-игра в настольный хоккей (аэрохоккей) с умным искусственным интеллектом. Разработана как часть социального офлайн-проекта **Anti-AI Shield**.

Игра работает прямо в браузере, не требует установки, не собирает данные и не зависит от внешних серверов после загрузки.

## ✨ Особенности

- 🧠 **Умный ИИ-противник:** Адаптивная логика, которая не застревает в углах и играет по правилам реального аэрохоккея (отыгрыш от бортов).
- 📱 **Кроссплатформенность:** Идеально работает на ПК (мышь), планшетах и смартфонах (сенсорный экран) с адаптивным интерфейсом.
- 🔊 **Процедурный звук:** Звуки ударов и отскоков генерируются в реальном времени через Web Audio API. Никаких внешних MP3-файлов, что гарантирует 100% офлайн-работу.
- 🗣️ **Голосовая озвучка:** Браузер озвучивает голы и результаты матча (Speech Synthesis API).
- 🛡️ **Приватность:** Нулевая телеметрия, отсутствие трекеров, рекламы и принудительных регистраций.

## 🚀 Как запустить

### Способ 1: GitHub Pages (Рекомендуемый)
Игра уже развернута и доступна по ссылке:  
🔗 **[Играть онлайн](https://твой-логин.github.io/anti-ai-table-hockey/)** *(замени на свою ссылку после публикации)*

### Способ 2: Локальный запуск
1. Скачай или склонируй этот репозиторий.
2. Убедись, что файл `favicon.ico` находится в той же папке, что и `index.html`.
3. Просто открой файл `index.html` двойным кликом в любом современном браузере (Chrome, Firefox, Safari, Edge).

## 🛠️ Технологии

- **Графика:** Three.js (WebGL)
- **Физика:** Кастомная аркадная физика столкновений и трения
- **Аудио:** Web Audio API (процедурная генерация) + Web Speech API
- **Стили:** Адаптивный CSS3 с поддержкой `clamp()`, Safe Area и мобильных жестов
